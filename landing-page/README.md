# Goliath of All Trade Landing Page

## Overview

This is the landing page for Goliath of All Trade, a platform empowering businesses with quantum computing and AI solutions.

## Components

### Navbar

The navigation bar component.

- Props: None
- Renders brand name and navigation links.

### Footer

The footer component.

- Props: None
- Renders company info, quick links, solutions, contact, and copyright.

### AIPRMIntegration

Integration with AIPRM for AI prompts and extensions.
